title: Assistant declines to create a promotion
schema_ref: "topics:troubleshooting-issue"
---

The assistant refuses to create the requested promotion. This is
usually because the request would conflict with an existing active
promotion — check what's currently running before trying again, or
ask the assistant to list active promotions.
