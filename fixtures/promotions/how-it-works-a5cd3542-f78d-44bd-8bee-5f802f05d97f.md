# How it works

You describe a promotion in plain language — for example, "give
returning customers 15% off orders over $50 through the end of the
month." The assistant reads {{client_name}}'s current promotion
rules first, so it won't create something that conflicts with an
existing one, like accidentally stacking two discounts that
shouldn't combine. Every change is shown to you for review before
it's applied, and every past change is logged.
