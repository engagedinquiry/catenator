# Getting started

A promotion has a discount type, an eligibility rule, and an expiry
date — the assistant fills all three in from your plain-language
request. Before applying any change, the assistant compares it
against every existing active promotion to catch conflicts like
accidental stacking.

Open the assistant, describe the promotion you want in plain
language, and review the change it proposes before approving it.
