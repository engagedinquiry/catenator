# Troubleshooting

If the assistant declines to create a promotion, it's usually
because the request would conflict with an existing active
promotion — check what's currently running before trying again. If
a promotion isn't applying at checkout, confirm its expiry date
hasn't passed and that the order actually meets its eligibility
rule (e.g. the minimum purchase threshold).
