# Refraction

Don't let it just sit there. Make it work.

## What you always knew about your users

You always knew an employee and a customer asking the same question weren't owed the same answer. You've probably said as much in a meeting. It just never made it into the system itself — the retrieval step doesn't know who's asking, so it can't answer them differently even when everyone agrees it should.

## Every asker gets its variant

The same underlying knowledge can be shaped for every persona who asks about it, not just answered once, generically, and hoped to be close enough for everyone.

> AI makes every variant possible and achievable. The missing piece was never capability. It was ever having asked the question.

## What actually changes, per asker

| Dimension | What it means for you |
|---|---|
| **Trust** | What an answer needs to be grounded in before it's given. An employee may need a citation. A customer may just need a confident, simple answer — but only if it's actually correct. |
| **Context** | What this asker is allowed to know, and what they're arriving with. An employee's context includes internal policy. A customer's doesn't. |
| **Content** | What's actually included in the answer. The same underlying source can produce a detailed, cited answer or a short, safe one. |
| **Time** | Whether the answer reflects the source as it stands now, or a stale version nobody's checked against the current document. |
| **Surface** | How the answer is displayed — present, but rarely where the actual risk in these systems lives. |

## The one non-negotiable: an answer with no grounding is not an answer

Every other persona distinction is about tone, depth, and what's included. This one isn't optional for any persona: if the system can't trace an answer back to something real, the correct response is saying so — not a fluent guess wearing the same confidence as a grounded answer would.

## Refining is normal — expected, even

If a persona's answers don't feel right, that's the governing document needing another pass, not refraction failing. Go back to what you said about who's asking and what they're owed, and the answers update from there.

## The test for whether it's working

If you can't point to what a persona was told and say why — which trust requirement, which context boundary — that's a sign the governing document needs another pass. Ask it plainly: *why did this asker get this answer, cited this way, and not another?* There should be an answer, and it should be yours.
