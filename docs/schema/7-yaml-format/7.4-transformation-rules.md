# Transformation rules

*This section is deferred to Catenator standard v1.5.0.*

Transformation rules define how a valid Catenator spec is converted into other artifacts — `CLAUDE.md`, PRD, README, backlog, or other outputs. The rules govern what each target artifact must contain, how spec items map to artifact sections, and what an agent is permitted to infer versus what it must take verbatim from the spec.

Topics to be covered in v1.5.0:

- Target artifact types in scope
- Mapping rules: spec item → artifact section
- Authored vs inferred content in output
- Handling of `display-name-source: authored` in generated output
- Attachment content in transformations
- Transformation fidelity requirements — what constitutes a correct transformation
- Validation of generated artifacts against the spec that produced them
